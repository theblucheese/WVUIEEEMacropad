
# WVU IEEE Macro Pad Workshop

Basic 3x3 Switch ESP32-C6 powered macro pad.

Also has basic OLED display and Rotary encoder that is connected to volume by default

Params can be changed in the settings to alter the Bluetooth name and Wifi Network settings

Programming of Switches is done via connecting to the captive network that the macropad creates, the details of this connection can be edited in the code

Works with most operating systems AFAIK
